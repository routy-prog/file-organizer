# File Organizer

Программа для автоматической сортировки файлов по папкам в зависимости от их расширения.

## Возможности

- Сортировка изображений
- Сортировка музыки
- Сортировка документов
- Сортировка Python-файлов
- Автоматическое создание папок
- Обработка неизвестных типов файлов

## Используемые технологии

- Python
- os
- shutil
